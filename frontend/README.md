# Legal Trend Radar - Frontend

Next.js (App Router) + TypeScript + Tailwind + Recharts dashboard. Talks
**only** to the FastAPI backend via `NEXT_PUBLIC_API_URL` - never directly to
law.go.kr.

```powershell
cd frontend
npm install
copy .env.local.example .env.local
npm run dev
```

Open http://localhost:3000, then http://localhost:3000/dashboard.

See the repo-root README for the full project overview, legal disclaimer,
and pipeline instructions.
